# Roll Call — ระบบเช็คชื่อนักศึกษาด้วยใบหน้า

เว็บแอปให้อาจารย์:
- สร้างห้องเรียนได้หลายห้อง
- เพิ่มรูปนักศึกษา (นำเข้าจากโฟลเดอร์ได้)
- เปิดกล้องเช็คชื่อแบบ real-time พร้อมกันภาพปลอม (anti-spoof) และเครื่องมือจัดการแฝด/หน้าคล้าย
- ปิดคาบแล้วได้ไฟล์ Excel

ข้อมูลทั้งหมด (รูป, embedding, ฐานข้อมูล) **เก็บอยู่ในเครื่องนี้เท่านั้น** ในโฟลเดอร์ `data/`

## 3. Pipeline และโมเดลที่ใช้

```
เฟรมจากกล้อง (browser getUserMedia → WebSocket)
 └─ YOLO26s face (fine-tune WIDER FACE, notebook 1)          models/yolo26s_face_640.onnx
     └─ crop สี่เหลี่ยม x1.5 → anti-spoof convnext_nano      models/antispoof_convnext_ft.onnx (notebook 2 + fine-tune notebook 3)
 └─ YOLO26n หามือถือ/จอ/รูปพิมพ์รอบใบหน้า (Roboflow)     models/spoof_yolo26n_640.onnx     (notebook 3)
     └─ SCRFD 5 จุด (ตา จมูก ปาก) → จัดหน้าตรง 112x112      models/det_10g.onnx              (InsightFace buffalo_l)
         └─ ArcFace R50 → embedding 512 มิติ                 models/w600k_r50.onnx            (InsightFace buffalo_l)
             └─ cosine similarity กับรูปอ้างอิงทุกรูปของห้อง
```

**ทำไมเลือกแบบนี้**
- **ใช้ ONNX Runtime ทั้งหมด** ไม่ต้องลง PyTorch
  - Windows ใช้ DirectML ซึ่งใช้การ์ดจอได้ทันทีโดยไม่ต้องลง CUDA
  - Docker ใช้ CPU และ image เล็ก
  - YOLO26 ใน `ultralytics` เวอร์ชันเก่าของเครื่องนี้ให้คะแนนไม่ตรงกับ ONNX จึงถอดผลเองตามรูปแบบของ notebook 1 (raw head + NMS)
- **Anti-spoof:** `convnext_aug / ema` จาก notebook 2 (ชนะ MobileNetV3 / EfficientNet-B0 ที่ degraded ACER 0.92% vs 1.6–1.8%) แล้ว fine-tune ต่อใน notebook 3 ด้วย Roboflow + Axon + CelebA (กันลืม)
- **ตรวจอุปกรณ์:** YOLO26n เทรนบน Roboflow *face-anti-spoofing-detection* (CC BY 4.0) mAP50 0.98
- **Embedding:** ใช้ ArcFace R50 (buffalo_l) ซึ่งแม่นที่สุดในกลุ่มนี้ และจัดหน้าตรงด้วยจุด landmark ก่อนสกัด ข้อจำกัดคือ license ใช้ได้เฉพาะงานวิจัย/การศึกษา (ไม่เชิงพาณิชย์)

### ความเร็ว (วัดจริง, 1 หน้าต่อเฟรม 960 px)
| เครื่อง | เวลา/เฟรม | ประมาณ |
|---|---|---|
| RTX 4050 Laptop (DirectML) | 50 ms (ไม่รวม YOLO26n 34 ms) | ~20 fps |
| CPU i7-13620H (ไม่ใช้ GPU) | 165 ms (ไม่รวม YOLO26n 134 ms) | ~6 fps |

แต่ละหน้าที่เพิ่มในเฟรมใช้ CPU อีกประมาณ 65 ms การเช็คชื่อทีละคนต้องการแค่ 3–5 fps

**สเปคเซิร์ฟเวอร์ CPU ที่แนะนำ:** 4–8 cores รุ่นใหม่ (เช่น Intel i5/i7 gen 10+ หรือ Ryzen 5 ขึ้นไป) และ RAM 4 GB ขึ้นไป (ระบบใช้ ~1.5 GB) ใช้ห้องเดียวต่อครั้งได้สบาย ถ้าเปิดหลายห้องพร้อมกันควรมี 8 cores ขึ้นไป หรือเปลี่ยน embedding เป็น buffalo_s (เร็วขึ้น ~3 เท่า แต่แยกหน้าคล้ายได้แย่กว่า)

## 4. กฎการเช็คชื่อ
- **เช็คชื่อสำเร็จ:** หน้าเดียวกัน (ติดตามข้ามเฟรม) ต้องเป็น **คนจริง** และ **ตรงกับคนเดิม** ต่อเนื่อง `confirm_frames` เฟรม (ค่าเริ่มต้น 5)
- **ไม่บันทึกซ้ำ:** คนที่เช็คแล้วจะขึ้นกรอบสีทอง "เช็คชื่อแล้ว"
- **ด่านคุณภาพ:** ตัดสินเฉพาะหน้าที่มองตรง (`max_yaw`, `max_pitch`) ไม่ติดขอบภาพ และไม่มืดเกิน ถ้าไม่ผ่านจะขึ้นคำแนะนำ เช่น "มองตรงที่กล้อง"
- **สงสัยภาพปลอม:** ไม่เช็คชื่อ และเก็บภาพหลักฐาน (หน้า + ภาพเต็มพร้อมกรอบอุปกรณ์) และเหตุผลไว้ที่ปุ่ม "หลักฐานสงสัยปลอม" (ดูหัวข้อ 5)
- **มา / สาย / ขาด:** คำนวณจากเวลาเริ่มคาบ + `late_minutes` ซึ่งแก้ได้ระหว่างคาบ
- **อาจารย์แก้เอง:** กด ✓ / ✕ ที่รายชื่อเพื่อเช็คหรือยกเลิก ระบบบันทึกว่าเป็น manual และลงใน log

### แฝด / หน้าคล้าย (หลายชั้นซ้อนกัน)
1. **ตอนเพิ่มรูป:** ถ้าคู่ไหน similarity ≥ `similar_warn` ระบบจะเตือนและจัดทั้งคู่เข้า **กลุ่มเสี่ยง** อัตโนมัติ อาจารย์ติ๊กเข้า/ออกเองได้
2. **คะแนนต่อคน = ค่าสูงสุดเทียบกับทุกรูปอ้างอิงของคนนั้น** ยิ่งมีหลายมุมยิ่งแม่น กลุ่มเสี่ยงแนะนำ 8–10 รูป
3. **เกณฑ์เข้มขึ้นสำหรับกลุ่มเสี่ยง:** ต้องมี similarity ≥ `risk_sim_threshold` และห่างจากอันดับ 2 ≥ `risk_margin`
4. **ตัวแยกแฝด (Fisher discriminant):** ถ้าอันดับ 1 และ 2 อยู่กลุ่มเสี่ยงทั้งคู่ และมีรูปคนละ ≥ 3 รูป ระบบจะหาทิศทางใน embedding ที่แยกสองคนนี้ได้ดีที่สุด (เรียนจากรูปของทั้งคู่โดยตรง) แล้วตัดสินเฉพาะคู่นี้ ต้องได้ความมั่นใจ ≥ `pair_min_confidence`
5. **ถ้ายังไม่แน่ใจต่อเนื่อง `ambiguous_frames` เฟรม → popup "ยืนยันตัวตน"**
   - อาจารย์เห็นภาพสดเทียบกับผู้สมัคร 2–3 คน แล้วกดเลือกเอง
   - ทุกการยืนยันลงใน log และ Excel
6. **เรียนรู้จากการยืนยัน:** ติ๊ก "เพิ่มภาพนี้เป็นรูปอ้างอิง" ได้ ภาพจากกล้องจริงช่วยให้แยกแฝดได้แม่นขึ้นทุกคาบ

แท็บ **ตรวจความคล้าย** มี heatmap ของทุกคู่ และรายการคู่ที่คล้ายที่สุดพร้อมรูปเทียบกันข้าง ๆ

## 5. กันภาพปลอม (3 ชั้น)
```
หน้าผ่านด่านคุณภาพ
 ├─ ชั้น 1  YOLO26n: หน้าอยู่ในกรอบมือถือ/จอ/รูปพิมพ์ ≥ 60%, conf ≥ device_conf (0.75)
 │          ติดกัน spoof_frames เฟรม → ปลอม  (ตรวจทุกเฟรม แม้ผ่านไปแล้ว)
 ├─ ชั้น 2  ConvNeXt: เฉลี่ย P(spoof) ของ average_frames เฟรม
 │          ≤ live_below (0.20) → คนจริง   |   ≥ spoof_above (0.90) → ปลอม
 └─ ชั้น 3  อยู่ระหว่างกลาง → สุ่มสั่ง "หันซ้าย" หรือ "หันขวา" แล้วหันกลับ
            ทำได้ภายใน challenge_timeout_sec → คนจริง | ไม่ได้ challenge_tries ครั้ง → ปลอม
```
- **เหตุผล:** ภาพปลอมหลุดอันตรายกว่าคนจริงต้องหันหน้าเพิ่ม 2 วินาที จึงให้โซน "ไม่แน่ใจ" ไปพิสูจน์ด้วยการหันหน้าแทนการเดา
  - รูปบนจอหรือกระดาษเป็นภาพแบน หันตามคำสั่งไม่ได้
  - ทิศเป็นแบบสุ่ม จึงเตรียมคลิปไว้ก่อนไม่ได้
- **ทิศ:** "ซ้าย" หมายถึงซ้ายของนักศึกษาเอง ระบบวัดจาก yaw ของจุด landmark 5 จุด บนภาพดิบจากกล้อง ส่วนลูกศรบนจอวาดตามโหมดกระจกให้อัตโนมัติ
- **ผลทดสอบ:** ดู `scripts/eval_testset.py` และหัวข้อผลการทดสอบในรายงาน
  - ภาพปลอมจากอุปกรณ์ที่ไม่เคยเห็น (Axon) ไม่มีภาพไหนผ่านได้ทันที ทุกภาพต้องผ่านการหันหน้าก่อน
  - รูปเพื่อนในห้องที่หน้าตรง: ผ่านทันที 85% ต้องหันหน้า 13% ถูกปฏิเสธ 1.5%
- **โหมด** (ตั้งค่า → Anti-spoof):
  - `block`: ปกติ
  - `warn`: เช็คชื่อแต่ติดธงในรายงาน
  - `off`: ปิดทั้ง 3 ชั้น
- **ระบบเก็บข้อมูลให้ fine-tune:**
  - ภาพหน้าตอนเช็คชื่อสำเร็จ เก็บเป็นตัวอย่างคนจริง
  - ภาพหลักฐานที่อาจารย์กด "ปลอมจริง" / "คนจริง"
  - ดาวน์โหลดเป็น zip ที่ **ตั้งค่า → ข้อมูลสำหรับปรับปรุงโมเดล**
- **ทดสอบ spoof ต้องใช้ภาพจริงจากกล้อง:** เปิดรูปบนมือถือ/จอ/กระดาษให้กล้องดู
  - การส่งไฟล์รูปเข้า API โดยตรง หรือการตัดแปะรูปในโปรแกรม ไม่ใช่การทดสอบที่ถูกต้อง

## 5.1 ทดสอบด้วยรูป/วิดีโอของเราเอง + เทียบเฉลย Excel
1. วางรูป (`.jpg .png`) และ/หรือวิดีโอ (`.mp4 .mov .avi`) ไว้ในโฟลเดอร์เดียวกัน (ค่าเริ่มต้น `image_pyiot\test set`)
2. ใส่ไฟล์เฉลย `.xlsx` 1 ไฟล์ในโฟลเดอร์นั้น แถวแรกเป็นหัวตาราง:
   | image_No | Member1 | Member2 | … | Expect (ไม่ใส่ก็ได้) |
   |---|---|---|---|---|
   | image1 | Bus | Tan | | |
   | clip2 | | | | spoof |
   - คอลัมน์แรกจับคู่กับชื่อไฟล์ ถ้าชื่อตรงกันหรือเลขตรงกันก็ได้ (`image1` = `01.jpg`)
   - `A/B` = เป็นคนใดคนหนึ่งก็ถูก (ใช้กับแฝด)
   - `Expect = spoof` หมายถึงคลิปหลอก ต้องไม่มีใครถูกเช็คชื่อ
3. รัน
   ```powershell
   cd C:\Ai\Roll_call\attendance_app
   .venv\Scripts\activate
   python scripts\run_test.py                      # ใช้ image_pyiot\test set
   python scripts\run_test.py "D:\คลิปทดสอบ"        # โฟลเดอร์อื่น
   ```
4. ครั้งแรกจะสร้าง `names.csv` (ชื่อเล่นอังกฤษ → ชื่อไฟล์รูปลงทะเบียน) ถ้ามีชื่อใหม่ในเฉลยให้เพิ่มแถวในไฟล์นี้
5. ผลอยู่ที่ `C:\Ai\Roll_call\test_results\<วันเวลา>\`
   - `report.xlsx`: ไฟล์ละ 1 แถว มีเฉลย / ระบบเช็คชื่อ / ถูก / ผิดคน / หาไม่เจอ / ผ่านไหม และสรุป Precision, Recall, F1
   - รูปที่วาดกรอบแล้ว
   - วิดีโอที่วาดกรอบแล้ว (เปิดด้วย VLC ถ้าโปรแกรมของ Windows เปิดไม่ได้)
- **รูป:** ตัดสินแบบ 1 เฟรม จึงหันหน้าไม่ได้ หน้าที่ต้องหันหน้าจะนับว่าผ่านแต่มีหมายเหตุ ส่วนหน้าที่ถูกตัดสินว่าปลอมจะไม่นับว่าเช็คชื่อ
- **วิดีโอ:** ใช้กฎเดียวกับหน้าเช็คชื่อจริงทุกอย่าง (ติดตามหน้า กันปลอม 3 ชั้น เช็คเมื่อครบ 5 เฟรม) และนับเวลาตามคลิป
  - ถ้าระบบสั่งหันหน้าแต่คนในคลิปไม่ได้หัน จะถูกตัดสินว่าปลอม
  - คลิปทดสอบจึงควรถ่ายแบบมองตรงนิ่ง ๆ 3–5 วินาที

## 7. Deploy ด้วย Docker (เซิร์ฟเวอร์ CPU)
ต้องติดตั้ง Docker ก่อน (Windows/Mac ใช้ Docker Desktop, Linux ใช้ Docker Engine) แล้วคัดลอกทั้งโฟลเดอร์ `attendance_app` (รวม `models/`) ไปที่เซิร์ฟเวอร์:

```bash
docker compose up -d --build      # สร้างและรัน (ครั้งแรกใช้เวลาสักพัก)
docker compose logs -f            # ดู log
docker compose down               # หยุด
```

จากนั้นเปิด `https://<IP เซิร์ฟเวอร์>:8000` แล้วกดยอมรับใบรับรอง self-signed
- **ข้อมูลอยู่ที่** `./data` บนเซิร์ฟเวอร์ (mount เป็น volume) ลบ container แล้วข้อมูลยังอยู่
- **ปรับจำนวน thread** ได้ที่ `OMP_NUM_THREADS` ใน `docker-compose.yml` (ให้เท่ากับจำนวน core)

## 8. ข้อมูลส่วนบุคคล (PDPA)
- **ขอความยินยอม:** ทุกครั้งที่เพิ่มรูปต้องติ๊กยืนยันว่าได้รับความยินยอม ระบบบันทึกเวลาไว้ที่นักศึกษาแต่ละคน
- **ลบได้ทุกระดับ:**
  - ลบรายรูป
  - ลบรายคน (รูป + embedding + ประวัติ)
  - ลบทั้งห้อง
  - ลบทั้งหมดที่หน้า **ตั้งค่า**
- **ไม่มีการส่งข้อมูลออกอินเทอร์เน็ต:** ฟอนต์และไลบรารีทั้งหมดอยู่ในเครื่อง
